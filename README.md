# 邮件归档管理系统

把客户发到 163 的邮件，按「日期 → 客户邮箱 → 每一封」整理到文件夹。

## 怎么用

1. 安装 Python 3.10 或更高版本
2. 双击 `打开页面.bat`，不要关闭弹出的黑窗口
3. 在页面里填 163 邮箱和授权码，点「开始整理这一天的邮件」

浏览器没自动打开时访问：http://127.0.0.1:8765/

授权码不是登录密码。在 mail.163.com → 设置 → POP3/SMTP/IMAP → 开启 IMAP → 生成授权码。页面里也有这几步说明。

第一次可先点「先看一次示例」，不连邮箱也能看效果。默认保存到桌面「邮件归档」。
